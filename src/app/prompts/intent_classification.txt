AVAILABILITY (query_items):
- ase neki, ase niki, ase ne, ase?, hai kya, available?

- laage, lage, lagibo, chahiye, need, diya, dibo, de, add

- one more, ek aur, add more, increase, change

GENERAL MENU (no product named):

### SPELLING TOLERANCE

Treat phonetic variations as same:
- daali = dali = dal
- koni = koni
- sabun = sabon

Do NOT fail due to spelling noise.

-----------------------------------
## INTENT DISAMBIGUATION (STRICT)

1. If message contains availability words:
   → sub_intent = query_items

2. If message contains "laage" / "need":
   → sub_intent = add_to_cart

3. If ONLY product name is mentioned:
   → assume add_to_cart

4. Questions ALWAYS override add_to_cart

5. If the assistant just listed numbered products and the customer replies with only a number, ordinal, or product name, treat as **add_to_cart** for that choice (the app resolves the number locally).

-----------------------------------
## CATALOGUE vs PRODUCT QUERY (VERY IMPORTANT)

- If NO specific product is identified AND message is like:
  "ki ase", "ki ase neki", "ache ki"
  → use key: "catalogue"

- If a PRODUCT alias is in the message + availability (ase neki / ase?):
  → use that product key with query_items (e.g. koni→eggs, daali→dal)

Examples:
- "koni ase neki" → eggs (koni = eggs; is it available?)
- "12 pack koni ase neki" → eggs, query_items, quantity "12 pack" (NOT add_to_cart)
- "daali ase neki" → dal
- "ki ase neki" → catalogue (what do you have?)
- "eggs available?" → eggs

## RULES

- Output **one entry per product or cart-level action** under `items`
- Keys must be normalized lowercase English product names
- For whole-cart actions use keys:
  - cart (view_cart)
  - checkout
  - clear_cart
  - menu (query_items)
  - help (general_enquiry)
  - catalogue (query_items when no product specified)

- Multiple actions → multiple keys
- Comma list → multiple items (default add_to_cart)
- modify_item_from_cart → use "+1", "3 packs", etc.
- Do NOT hallucinate products
